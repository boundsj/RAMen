# Verification records

The [native verification summary](final-qa-evidence.md) records the tested
runtime, measured results and remaining coverage limits. The
[final QA runbook](final-qa.md) provides repeatable checks for future changes.
Native captures and their provenance are in the
[gallery](../screenshots/final-qa/README.md).

This repository starts from a clean source snapshot. Revision hashes and
review numbers in historical design notes, runbooks and capture provenance
identify pre-publication development work retained in a separate private
archive. They are not commits or pull requests in this repository. Historical
results remain tied to the versions they name; starting a new repository does
not extend their coverage or claim that unexecuted checks passed.
